📥 Import Data Pemilih

Upload data siswa/pengurus MPK menggunakan file CSV UTF-8. Sistem akan membuat NIS unik dan mengisi pin_hash secara otomatis. Pemilih tetap login menggunakan Nama + Jabatan.

Format CSV

File harus memiliki dua kolom dengan header berikut:

Nama,Jabatan

Contoh struktur file: kolom Nama berisi nama lengkap, kolom Jabatan berisi jabatan pemilih. Jangan mengubah nama header.
